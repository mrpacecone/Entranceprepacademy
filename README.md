## 🚀 Deploy to GitHub Pages (Step-by-Step)

### Step 1 — Create Repository
1. Go to [github.com](https://github.com) and sign in
2. Click the **"+"** button → **"New repository"**
3. Name it: `ballb-entrance` (or any name you prefer)
4. Set to **Public** (required for free GitHub Pages)
5. Do **NOT** check "Add README" — leave it empty
6. Click **"Create repository"**

### Step 2 — Upload Files
**Option A: Upload via GitHub website (easiest)**
1. In your new repository, click **"uploading an existing file"**
2. Upload ALL files maintaining this folder structure:
   ```
   index.html          ← MUST be at root
   404.html
   _config.yml
   assets/
     css/
       main.css
     js/
       core.js
   ```
3. Click **"Commit changes"**

**Option B: Using Git (advanced)**
```bash
git init
git add .
git commit -m "Initial commit — BALLB Entrance Hub"
git remote add origin https://github.com/YOUR_USERNAME/ballb-entrance.git
git push -u origin main
```

### Step 3 — Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** tab
3. In the left sidebar, click **Pages**
4. Under **"Source"**, select **"Deploy from a branch"**
5. Under **"Branch"**, select **"main"** and **"/ (root)"**
6. Click **Save**
7. Wait 1–2 minutes

### Step 4 — Access Your Site
Your site will be live at:
```
https://YOUR_USERNAME.github.io/ballb-entrance/
```

GitHub will show you the URL in Settings → Pages.
